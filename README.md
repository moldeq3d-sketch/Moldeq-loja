# Moldeq — Loja Online

Site de catálogo para a Moldeq, com carrinho via WhatsApp e painel do vendedor conectado ao Supabase.

## Rodar localmente
```
npm install
npm run dev
```

## Publicar (Vercel)
1. Suba esta pasta para um repositório no GitHub
2. Em vercel.com, "Add New Project" → importe o repositório
3. Framework preset: Vite (detectado automaticamente)
4. Deploy

## Painel do vendedor
- Acesse o site → ícone de cadeado no topo → PIN: 1234
- Configure o número de WhatsApp em Configurações antes de divulgar o site
